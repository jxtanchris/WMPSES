# WMPSES - 工业废气治理工实操模拟仿真考试系统（1.1.1 设备验收）

基于《工业废气治理工国家职业技能标准（2019年版）》（6-28-02-05）二级/技师 **“1.1.1 系统启动前设备验收”** 开发的 2D 热点交互式实操模拟仿真考试系统，内置 **SQLite 8 表关系型后台数据库与零依赖本地服务**、**表驱动否定项规则引擎**、**交互式项目甘特图看板** 以及完整的 **FileMaker 关系型题库与考务 XML 脚本**。

---

## 一、核心功能特性

1. **2D 全景装置热点交互**：
   - 以“碱洗预处理＋三室蓄热式焚烧（RTO）联合装置”全景图为操作舞台，设置 **8 个核心设备部位热点**，共 **15 道仿真习题（满分 50 分）**。
   - 完整覆盖基准场景的 **6 项重大缺陷（D1~D6）、4 项一般缺陷（D7~D10）、3 项干扰项（G1~G3）**、受限空间安全红线（N3）及总体验收放行判定（N2）。
2. **SVG 现场工况可视化**：
   - 每个设备热点弹窗顶部均配有高保真工业 SVG 工况特写卡（压力表 0.28MPa 与 0 流量计对照、乳化油标 vs 正常油标视镜、LALL-101 联锁旁路与假液位、CEMS 漂移与过期标签、切换阀 0.32MPa 气源与 9s 迟滞等）。
3. **三态工作模式**：
   - **🎯 练习演示模式**：单题即答即评，展示标准依据与详细解析。
   - **📝 正式考试模式**：30 分钟倒计时、按 `WMPSES_否定项规则` 表动态执行 N1/N2/N3 核验与判零、交卷生成成绩单报告与错题复盘，并实时落库成绩主从表。
   - **🛠️ 教师编辑/标点模式**：支持直接在图上拖拽调整热点坐标、点击图面新增热点、可视化增删改习题，修改即时自动写入本地 SQLite 数据库并同步更新 FileMaker CSV 种子文件。
4. **SQLite 8 表关系型数据库 + 表驱动否定项引擎**：
   - 与 FileMaker 8 表结构 **1:1 严格对齐**，包含：`WMPSES_试卷场景`、`WMPSES_设备热点`、`WMPSES_习题库`、`WMPSES_考试记录`、`WMPSES_作答明细`、`WMPSES_否定项规则`、`WMPSES_验收规范与确认单`、`WMPSES_工况资料与引用标准`。
   - **表驱动否定项判定**：不再将“漏判 ≥3 项判零”写死在前端代码里，可在界面 **「⚙️ 数据库 / 题库 -> ⚖️ 否定项规则表配置」** 中直接启停 N1/N2-A/N2-B/N3、调整阈值和惩罚动作并落库。
   - **台账与验收方案库**：顶部 **「📋 台账与验收方案」** 支持直接查阅 4 份现场工况台账、6 方面 24 项验收确认单规范（支持一键跳转定位图上对应设备）及 14 部附录 C 引用国标。
   - **数据库表实时查看器**：可在界面 **「⚙️ 数据库 / 题库 -> 🗄️ SQLite 数据库表预览」** 直接查看 SQLite 全部 8 张表的实时记录。
5. **FileMaker 无缝对接与项目甘特图**：
   - 内置 `FMDataAdapter` 与 `window.FMExam` 全局桥接，支持本地 SQLite、FileMaker WebViewer 双向脚本、FileMaker Data API / REST 与纯离线本地模式。
   - 内置 [gantt-roadmap.html](gantt-roadmap.html) 交互式全周期甘特图看板，支持“11周单题试点 (220人天)”与“12个月全套13题推广”视图切换、进度勾选与 CSV 导出。

## 二、快速启动

### 方式 1：启动 SQLite 后台服务（推荐，支持教师编辑实时存库与成绩落库）
- **macOS Finder 一键启动**：直接双击项目根目录的 `启动SQLite后台服务.command`；
- **或命令行启动**：
  ```bash
  python3 server.py --port 8765
  ```
  启动后在浏览器访问 **http://127.0.0.1:8765**（或直接双击 `index.html` 亦可自动跨域连上本地 SQLite 服务）。

### 方式 2：纯离线静态演示
- 无需启动 Python 服务，直接双击打开 `index.html` 即可全屏离线运行（自动降级使用内置题库与浏览器本地存储）。

### 方式 3：查看项目全周期甘特图与待办清单
- 点击系统顶部 **「📅 任务清单与甘特图」** 或直接双击 `gantt-roadmap.html`，文档版见 `启动前设备验收仿真考试系统_任务清单与甘特图.md`。

## 三、SQLite 8 表关系架构概览

| 序号 | 表名 | 业务含义 | 初始示范记录 |
| :-: | :--- | :--- | :---: |
| 1 | `WMPSES_试卷场景` | 试卷与工艺场景总表（V1 碱洗+RTO 已启用，预留 V2/V3 变式） | 3 条 |
| 2 | `WMPSES_设备热点` | 全景图设备部位热点坐标（X/Y 百分比）、位号与工况卡片类型 | 8 条 |
| 3 | `WMPSES_习题库` | 实操习题（题干、OptionA~E、AnswerKeys、分值、缺陷代码/级别、解析） | 15 条（50分） |
| 4 | `WMPSES_考试记录` | 考生正式考试交卷主记录（得分、耗时、合格判定、否定项触发理由） | 交卷生成 |
| 5 | `WMPSES_作答明细` | 每次交卷的逐题作答子记录（用于后续统计各缺陷点错误率） | 交卷生成 |
| 6 | `WMPSES_否定项规则` | **表驱动一票否决规则库**（N1/N2-A/N2-B/N3 启停开关、阈值与判零动作） | 4 条 |
| 7 | `WMPSES_验收规范与确认单` | 对应《设计方案》表3与附录A的 6 大方面 24 个标准核查项 | 24 条 |
| 8 | `WMPSES_工况资料与引用标准` | 4 份电子工况台账（检修/设备/上次验收/CEMS）+ 14 部附录C引用国标 | 18 条 |
