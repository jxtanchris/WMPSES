# WMPSES - 工业废气治理工实操模拟仿真考试系统（1.1.1 设备验收）

基于《工业废气治理工国家职业技能标准（2019年版）》（6-28-02-05）**“1.1.1 系统启动前设备验收”** 开发的 **2D / 3D 多视图热点交互式实操模拟仿真考试系统**，支持 **多级别报考场景（已内置 V1 二级/技师 与 V2 三级/技师）**、**SQLite 11 表关系型后台数据库与零依赖本地服务**、**动态 SVG 工况可视化与实时仿真调节器**、**独立题库池与集中习题总表（支持 CSV 批量导入）**、**文字简答题与考评员手工盲评阅卷工作台**、**表驱动否定项规则引擎**、**Bearer Token + RBAC 前后端强鉴权** 以及完整的 **FileMaker 关系型题库与考务 XML 脚本**。

---

## 一、核心功能特性

1. **2D / 3D 多视图全景与多级别试卷场景**：
   - 支持 **3D 环绕视图、第一人称漫游、2D 平面全景** 自由切换，并支持自定义 2D 底图、360° 3D 全景底图与 `.glb` 真 3D 模型持久化入库（`WMPSES_试卷场景`）。
   - 已预置并启用 2 套完整考卷场景，**考生在登录时及未封卷前可自由选择报考级别**：
     - **`WMPSES-1.1.1-V1`（二级/技师）**：8 个设备部位热点，15 道客观仿真习题（满分 50 分，合格线 30 分）。
     - **`WMPSES-1.1.1-V2`（三级/技师）**：8 个设备部位热点，15 道客观题 + **2 道文字简答题**（共 17 题，满分 60 分，合格线 36 分）。
   - 完整覆盖基准场景的 **6 项重大缺陷（D1~D6）、4 项一般缺陷（D7~D10）、3 项干扰项（G1~G3）**、受限空间安全红线（N3）及总体验收放行判定（N2）。
2. **SVG 现场工况可视化 + 实时参数推演 + 自定义专业仪表模板库**：
   - 每个设备热点弹窗顶部的工业 SVG 工况特写卡，由 `WMPSES_设备热点.WidgetParamsJSON` 与 `WMPSES_工况卡片模板` 双表联合驱动（支持压力表指针旋转、液位/油位柱升降、阀门开闭、法兰螺栓缺失、CEMS 零点漂移等动态绘制）。
   - 在 **练习演示** 与 **教师编辑/标点** 模式下提供 **「🎛️ 现场工况仿真调节器」**，可直接拖动滑块或切换阀门/联锁实时推演上方仪表图像；有编辑权限的角色可将推演数值一键 **「💾 将当前模拟数值保存为题库默认值」** 写入 SQLite 并自动同步场景描述。
   - 提供 **「专业仪表模板构建器」**（支持从热点编辑弹窗「➕ 新增/管理模板」或设置中心「🎛️ 管理专业仪表模板」打开），可自由组合 **8 类工业现场 SVG 仪表/设备部件**（或上传局部特写图）、自定义可调参数与上下限，即时预览并存入 `WMPSES_工况卡片模板` 表，自动扩展「顶部工况可视化卡片」选择源。
3. **三态工作模式、独立题库池与考评员手工盲评阅卷**：
   - **🎯 练习演示模式**：客观题单题即答即评，文字简答题支持对照参考评分要点，开放现场工况仿真调节器进行参数推演。
   - **📝 正式考试模式**：30 分钟倒计时、按 `WMPSES_否定项规则` 表动态执行 N1/N2/N3 核验与判零；**考生交卷后立即封卷**（不可查分、看解析、重考或切卷），成绩实时写入主从表（`WMPSES_考试记录` + `WMPSES_作答明细`）；含文字简答题的答卷自动进入 **`待阅卷`** 状态。
   - **✍️ 考评员手工阅卷工作台**：考评员（及审题专家/命题教师/管理员）可在「📊 考生成绩表」打开待阅卷答卷，默认启用 **🙈 盲评匿名模式**，对文字简答题逐题手工打分与写评语（客观题自动判分只读锁定不可篡改），提交后自动核算 `客观分 + 主观分` 并更新合格状态与阅卷人审计留痕。
   - **🛠️ 教师编辑/标点模式 + 📝 集中习题总表 & 独立题库池**：支持图上拖拽热点、点击新增热点、更换 2D/3D 底图与 `.glb` 模型；亦可在 **「📝 习题总表」** 不点图直接增删改查全部习题、CSV 批量导入导出，并支持**先将习题单独设计在「独立题库池」中，再到热点编辑器内一键勾选关联或移回题库池**。
4. **单表统一人员认证、Bearer Token 会话与前后端 RBAC 强校验**：
   - 在 `WMPSES_用户人员` 单表中以 `RoleType` 区分 **考生、命题教师、审题专家、考评员、监考员、系统管理员**，`Password` 列采用 **SHA-256 哈希加密存储**（预设初始密码统一为 `123456`），服务端响应统一脱敏不暴露密文。
   - 后端 `server.py` 启用 **Bearer Token 滚动会话（12h）与接口级 RBAC 角色强校验**，防止跳过前端 UI 直接调用 API 越权或提权（非系统管理员禁止创建/修改/删除系统管理员账号，改密与考生交卷强制绑定当前登录会话本人）。
   - 退出登录或刷新页面触发 `[未登录]` 安全门禁：仅保留登录入口并锁定主舞台，必须重新认证后方可操作。
5. **MySQL 8.0 / SQLite 双引擎关系型数据库 + 可在线维护台账方案库 + 表驱动否定项引擎**：
   - 前端自动识别当前连接的数据库引擎（**MySQL 8.0** 或 **SQLite**），支持直接在界面 **「⚙️ 数据库 / 题库 -> 🗄️ 数据库表预览」** 查看实时记录（密码列自动脱敏）。
   - **「📋 台账与验收方案」** 收录现场工况电子台账、验收规范确认单（支持一键跳转至图上对应设备）、附录 C 引用国标及否定项规则；**考生/考评员只读查阅，命题教师/审题专家/系统管理员支持直接在弹窗内在线新增、编辑、删除并实时落库**。
   - **「⚖️ 否定项规则表配置」** 支持直接启停 N1/N2-A/N2-B/N3、调整阈值和惩罚动作并落库，交卷判分实时按规则表执行。

## 二、快速启动

### 方式 1：启动 SQLite 后台服务（推荐，支持端口自检与局域网多机考试）
- **macOS Finder 一键启动**：直接双击项目根目录的 `启动SQLite后台服务.command`，脚本会自动完成：
  1. **环境与数据库自检**：校验 Python 3、`server.py` 与 `db/schema.sql`；
  2. **端口占用自检与冲突释放**：检测 `8765` 端口若被旧实例占用则自动停止释放；若仍被系统受保护进程占用，自动顺延扫描 `8766~8785` 空闲端口；
  3. **局域网（`0.0.0.0`）IP 自动探测**：默认监听所有网卡接口，在终端与系统界面 **「⚙️ 数据库 / 题库 -> 🔗 数据源与 FileMaker 配置」** 实时显示 **教师本机地址** 与 **同网段考生机免配置访问地址**；同网段其他考生机在浏览器打开 `http://<教师机局域网IP>:8765` 后，前端会自动同源直连教师机 SQLite 数据库。
- **命令行启动**：
  ```bash
  # 默认监听 0.0.0.0:8765，开启端口自检清理旧进程与空闲端口顺延
  python3 server.py

  # 如需仅限本机访问或关闭自动清理/顺延
  python3 server.py --host 127.0.0.1 --port 8765 --no-kill-existing --no-auto-port
  ```
  启动后本机可在浏览器访问 **http://127.0.0.1:8765**（或直接双击 `index.html` 亦可自动连接本地 SQLite 服务）。

### 方式 2：70~200 人高并发考场生产部署（Docker Compose + MySQL 8.0 + Nginx + FastAPI）
适用于多机同时开考与集中交卷场景（InnoDB 行级锁、连接池、Nginx 静态缓存 + Gzip、4 Worker FastAPI、无状态签名 Token、交卷幂等重试、错峰提交与 15 秒自动答题草稿防丢）：
```bash
# 1. 复制环境变量模板并修改密码与签名密钥（.env 已加入 .gitignore，不会上传至 GitHub）
cp .env.example .env

# 2. 一键启动 MySQL 8.0 + FastAPI (4 Workers) + Nginx（自动迁移现有 wmpses.db 至 MySQL）
docker-compose up -d --build

# 3. 考场浏览器统一访问（默认端口 8080）
#    http://<服务器局域网IP>:8080
```
- **数据持久化与备份 / 跨机迁移**：
  - MySQL 数据已持久化至 Docker 命名卷 `wmpses_mysql_data`（对应容器内 `/var/lib/mysql`），`docker-compose down` / 重启不会丢数据（**切勿随意执行 `down -v`**）。
  - 备份与跨机恢复命令：
    ```bash
    # 导出备份
    docker exec wmpses-mysql mysqldump -u root -p<root密码> wmpses > wmpses_backup.sql
    # 在新机器恢复
    docker exec -i wmpses-mysql mysql -u root -p<root密码> wmpses < wmpses_backup.sql
    ```
  - **纯内网离线部署**：在有网机器执行 `docker save -o wmpses-images.tar mysql:8.0 nginx:1.27-alpine wmpses_app:latest`，拷贝至内网机器执行 `docker load -i wmpses-images.tar && docker-compose up -d --no-build`。
- **Navicat / DBeaver 连接 MySQL**：主机 `127.0.0.1`（或服务器局域网 IP）、端口 `3306`、库名 `wmpses`、用户 `wmpses`（或 `root`）、密码见 `.env`。
- **手动全量重导 SQLite 数据到 MySQL**：
  ```bash
  docker exec -it wmpses-app python3 -m db.migrate_sqlite_to_mysql --force
  ```
- **切回 SQLite 单机模式**：运行 `docker-compose down` 停止容器，再双击 `启动SQLite后台服务.command` 或运行 `python3 server.py`（访问 `http://127.0.0.1:8765`）即可。
- **连接外部已有 MySQL**：设置环境变量 `WMPSES_DB_BACKEND=mysql` 及 `WMPSES_MYSQL_HOST/PORT/USER/PASSWORD/DATABASE` 后直接运行 `uvicorn app_server:app --host 0.0.0.0 --port 8765 --workers 4`。

### 方式 3：纯离线静态演示
- 无需启动 Python 服务，直接双击打开 `index.html` 即可运行（自动使用内置默认题库、本地用户档案与 `localStorage` 本地缓存，同样支持 SHA-256 本地登录校验与密码修改）。

## 四、工况数值模拟、新增部位与专业仪表模板操作指南

### 1. 热点弹窗中的工况图与数值存储在哪里？如何模拟调整？
- **数据存储位置**：各设备热点的顶部 SVG 样式类型与数值存放在 SQLite **`WMPSES_设备热点`** 表的 `WidgetType` 与 `WidgetParamsJSON` 字段中（离线/导出时对应 `question-bank.js` 中各热点的 `widgetType` 与 `widgetParams`），由 [visual-widgets.js](js/visual-widgets.js) 实时解析绘制。
- **实时模拟调节方式**：
  1. 在 **练习演示** 或 **教师编辑/标点** 模式下点击任意热点，顶部弹窗内会自动渲染 **「🎛️ 现场工况仿真调节器」**；
  2. 拖动压力、液位、温差、超期天数等滑块，或切换阀门开启/关闭、SIS 联锁投用/旁路等下拉选项，上方 SVG 仪表图形会即时联动变化；
  3. 点击 **「↺ 恢复基准值」** 可一键还原；在具备编辑权限时，点击 **「💾 将当前模拟数值保存为题库默认值」** 会将该数值永久写入 SQLite 并将修改记录追加至 `WMPSES_题库变更日志`。

### 2. 如何在装置全景图上新增一个设备部位？
1. 使用 **命题教师**（如 `TC-GY-01`）或 **审题专家 / 系统管理员** 登录系统，切换到顶部 **「🛠️ 教师编辑/标点」** 模式。
2. 点击黄色工具条中的 **「➕ 在图上新增热点」** 按钮（按钮提示将变为「🎯 请在下方图片点击选点（点击取消）」）。
3. 在全景图的目标设备位置单击鼠标，系统即按点击处相对坐标（`X`、`Y` 百分比）生成新设备部位热点并自动写入 SQLite，随后立即弹出 **「编辑热点部位与关联习题」** 编辑器，可继续修改：
   - 设备位号、部位名称、所属验收方面、精确 X/Y 坐标；
   - **「顶部工况可视化卡片」** 选择源及下方对应的仪表工况参数默认值；
   - 通过 **「➕ 新增习题」** 配置该部位的单选/多选/判断试题、分值、缺陷代码/级别、标准依据与解析。

### 3. 如何新增自定义「专业仪表模板」（扩展可视化卡片选择源）？
1. 打开 **「专业仪表模板构建器」**：
   - 在 **热点编辑器** 顶部「顶部工况可视化卡片」右侧点击 **「➕ 新增/管理模板」**；
   - 或在 **「⚙️ 数据库 / 题库 -> 📦 题库管理与考生信息」** 中点击 **「🎛️ 管理专业仪表模板」**。
2. 点击 **「➕ 清空新建模板」**，输入唯一的英文/数字模板编码（如 `pump_seal_monitor`）与下拉显示名称。
3. 分别选择 **左侧面板** 与 **右侧面板** 的 SVG 部件（支持以下 **8 类可自由组合组件**）：
   - `gauge_dial`：圆形指针压力/真空表
   - `pipe_valve_flow`：工艺管线 + 阀门 + 数字流量计
   - `sight_glass`：立式液位计 / 轴承油标视镜
   - `dcs_interlock`：DCS / SIS 联锁与参数趋势看板
   - `flange_bolts`：圆形法兰螺栓紧固检查盘
   - `cert_nameplate`：强检合格证与设备铭牌色标卡
   - `gas_cems_alarm`：气体报警仪 / CEMS 诊断面板
   - `custom_image_card`：自定义上传现场特写图 + 读数角标（选中后可上传局部设备照片）
4. 在参数配置表中调整各可调参数的标签、最小值/最大值/步长、单位和默认值，实时检查底部 **「👁️ 实时 SVG 渲染预览」**。
5. 点击 **「💾 保存模板到数据库」** 写入 `WMPSES_工况卡片模板`（同步更新 `9_WMPSES_工况卡片模板.csv`），新模板会立即出现在「顶部工况可视化卡片」选择列表中（内置 `TPL-01`~`TPL-09` 受保护不可删除，自定义模板支持编辑与删除）。

### 4. 如何单独设计题库、批量导入并在热点中关联已有题目？
1. **集中录题 / 先入独立题库池**：进入 **「🛠️ 教师编辑/标点」→「📝 习题总表」**（或「⚙️ 数据库 / 题库 → 📝 习题总表」），点击 **「➕ 新增独立/热点习题」**；归属部位可选择具体设备，或默认选中 **「📌 暂不关联热点（放入独立题库池）」** 先行单独设计题目（支持单选、多选、判断、文字简答题）。
2. **CSV 模板批量导入导出**：在「📝 习题总表」点击 **「⬇️ 导出 CSV 模板」** 用 Excel 编辑后，通过 **「⬆️ 批量导入 (.csv)」** 批量入库（CSV 中设备位号留空即自动进入独立题库池）。
3. **热点编辑器关联 / 移回**：点击任意设备热点打开编辑器，点击 **「🔗 从题库关联已有题目」** 可搜索并多选独立题库池题目直接移入关联（或从其他热点复制复用）；每道已关联题目也可点 **「🔓 移回题库池」** 取消关联而不丢题。

### 5. 文字简答题命制与考评员手工盲评阅卷流程
1. **命制文字简答题**：在热点编辑器或习题总表中将题型选为 **「文字简答题（考评员手工阅卷）」**，填写分值、题干、标准依据及参考评分要点并保存（`WMPSES-1.1.1-V2` 三级/技师场景已内置 2 道示范简答题）。
2. **考生作答与入队**：考生选择 `V2` 场景进入正式考试并填写文字简答题，交卷封卷后该答卷自动标记为 **`⏳ 待阅卷`**。
3. **考评员盲评打分**：使用考评员账号（如 `KP-2025-08` 赵丽华）登录，自动进入 **「📊 考生成绩表」**，点击对应答卷的 **「✍️ 手工阅卷」** 打开阅卷工作台（默认开启 **🙈 盲评匿名模式**），逐题输入得分与评语后点击 **「💾 提交手工阅卷打分」**，系统自动核算总分、更新合格状态并写入阅卷人审计记录（客观题得分全程锁定不可篡改）。

### 6. 考生报考级别 / 考试场景选择
- **登录时选择**：登录弹窗内置 **「📚 报考级别 / 考试场景」** 下拉框，自动列出所有状态为 `已启用` 且已配置热点的场景（如 `V1 二级/技师`、`V2 三级/技师`），登录后直接进入所选考卷。
- **未封卷前快捷切换**：考生登录后，顶部姓名徽章旁提供只读下拉框方便在练习模式切换考卷；**正式考试交卷封卷后自动禁用锁定**。

## 六、本地后台 HTTP REST API 清单（`server.py`）

默认监听 `0.0.0.0:8765`，静态资源托管与 API 共端口零跨域开销；敏感接口通过 `Authorization: Bearer <token>` 执行服务端 RBAC 角色强校验：

| 方法 | 路径 | 权限要求 | 用途说明 |
| :--- | :--- | :--- | :--- |
| `GET` | `/api/health` | 公开 | 健康检查，返回 SQLite 服务状态、监听端口、本机/局域网 URL 及 11 表统计 |
| `GET` | `/api/bank` | 公开 | 获取指定 `examId` 的试卷场景、热点、已关联习题、独立题库池 (`unassignedQuestions`)、规则、台账与模板 |
| `GET` | `/api/scenes` | 公开 | 获取全部试卷场景列表及热点/习题/底图/GLB 统计 |
| `GET` | `/api/scene-model` | 公开 | 下载指定 `examId` 的自定义 `.glb` 3D 模型二进制流 |
| `GET` | `/api/templates` | 公开 | 获取 `WMPSES_工况卡片模板` 全量模板列表 |
| `GET` | `/api/users` | 公开脱敏 / 考务管理完整 | 未登录/考生仅返回登录页最小公开字段；考务与管理角色返回脱敏人员名册与变更审计日志 |
| `GET` | `/api/results` | 考务与管理角色 | 查询全考场考生成绩列表（含客观分、主观分、阅卷状态与阅卷人） |
| `GET` | `/api/results/detail` | 考务与管理角色 | 查询单份考卷主记录与逐题作答明细（供考评员手工阅卷） |
| `GET` | `/api/tables` | 考务与管理角色 | 返回 SQLite 全部 11 张表实时结构与行数据快照（用户密码列自动脱敏） |
| `POST` | `/api/auth/login` | 公开 | 服务端 SHA-256 鉴权，签发 12 小时滚动 `Bearer Token` 并返回脱敏用户对象 |
| `POST` | `/api/auth/logout` | 公开 | 销毁当前 `Bearer Token` 会话 |
| `POST` | `/api/auth/password` | 已登录本人 | 校验原密码后更新当前会话本人 SHA-256 密码（强制绑定 Token 对应用户） |
| `POST` | `/api/results` | 考生/编辑角色 | 写入正式考试交卷成绩与逐题明细（考生强制绑定本人身份，含简答题自动置为待阅卷） |
| `POST` | `/api/results/grade` | 考评员/审题/命题/管理员 | 提交文字简答题手工打分与评语（禁止改客观题，自动重算总分与合格状态） |
| `POST` | `/api/bank` | 审题/命题/管理员 | 保存热点、习题、独立题库池、仪表参数与否定项规则，写入变更日志并同步 CSV |
| `POST` | `/api/scenes` | 审题/命题/管理员 | 新建或更新试卷场景元数据及 2D/3D 底图 |
| `POST` | `/api/scene-model` | 审题/命题/管理员 | 上传 `.glb` 真 3D 模型二进制流至 SQLite BLOB |
| `POST` | `/api/scene-model/clear` | 审题/命题/管理员 | 清除指定场景的自定义 `.glb` 模型 |
| `POST` | `/api/templates` | 审题/命题/管理员 | 新增或更新自定义专业仪表模板（同步导出 CSV） |
| `POST` | `/api/templates/delete` | 审题/命题/管理员 | 删除指定自定义模板（内置模板受保护不可删除） |
| `POST` | `/api/users` | 审题/命题/管理员 | 新增或更新人员记录（非系统管理员禁止创建或修改「系统管理员」账号） |
| `POST` | `/api/users/delete` | 命题/管理员 | 删除指定人员记录（禁止自删，非系统管理员禁止删除「系统管理员」账号） |
| `POST` | `/api/scenes/delete` | 命题/管理员 | 删除指定自定义试卷场景（主基准卷 `WMPSES-1.1.1-V1` 受保护） |
| `POST` | `/api/bank/reset` | 命题/管理员 | 恢复出厂示范题库（保留既有考生成绩）并重建 CSV 种子文件 |
