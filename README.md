# WMPSES - 工业废气治理工实操模拟仿真考试系统（1.1.1 设备验收）

基于《工业废气治理工国家职业技能标准（2019年版）》（6-28-02-05）二级/技师 **“1.1.1 系统启动前设备验收”** 开发的 2D 热点交互式实操模拟仿真考试系统，内置 **SQLite 11 表关系型后台数据库与零依赖本地服务**、**动态 SVG 工况可视化与实时仿真调节器**、**模块化专业仪表模板构建器**、**表驱动否定项规则引擎**、**统一人员 SHA-256 认证与角色权限控制（RBAC）**、**题库变更审计日志** 以及完整的 **FileMaker 关系型题库与考务 XML 脚本**。

---

## 一、核心功能特性

1. **2D 全景装置热点交互**：
   - 以“碱洗预处理＋三室蓄热式焚烧（RTO）联合装置”全景图为操作舞台，设置 **8 个核心设备部位热点**，共 **15 道仿真习题（满分 50 分）**。
   - 完整覆盖基准场景的 **6 项重大缺陷（D1~D6）、4 项一般缺陷（D7~D10）、3 项干扰项（G1~G3）**、受限空间安全红线（N3）及总体验收放行判定（N2）。
2. **SVG 现场工况可视化 + 实时参数推演 + 自定义专业仪表模板库**：
   - 每个设备热点弹窗顶部的工业 SVG 工况特写卡，由 `WMPSES_设备热点.WidgetParamsJSON` 与 `WMPSES_工况卡片模板` 双表联合驱动（支持压力表指针旋转、液位/油位柱升降、阀门开闭、法兰螺栓缺失、CEMS 零点漂移等动态绘制）。
   - 在 **练习演示** 与 **教师编辑/标点** 模式下提供 **「🎛️ 现场工况仿真调节器」**，可直接拖动滑块或切换阀门/联锁实时推演上方仪表图像；有编辑权限的角色可将推演数值一键 **「💾 将当前模拟数值保存为题库默认值」** 写入 SQLite 并自动同步场景描述。
   - 提供 **「专业仪表模板构建器」**（支持从热点编辑弹窗「➕ 新增/管理模板」或设置中心「🎛️ 管理专业仪表模板」打开），可自由组合 **8 类工业现场 SVG 仪表/设备部件**（或上传局部特写图）、自定义可调参数与上下限，即时预览并存入 `WMPSES_工况卡片模板` 表，自动扩展「顶部工况可视化卡片」选择源。
3. **三态工作模式与权限联动**：
   - **🎯 练习演示模式**：单题即答即评，展示标准依据与详细解析，并开放现场工况仿真调节器进行参数推演。
   - **📝 正式考试模式**：30 分钟倒计时、按 `WMPSES_否定项规则` 表动态执行 N1/N2/N3 核验与判零、绑定登录人员档案（`fk_UserID`）交卷生成成绩单报告与错题复盘，并实时写入成绩主从表（`WMPSES_考试记录` + `WMPSES_作答明细`）。
   - **🛠️ 教师编辑/标点模式**：支持直接在全景图上拖拽调整热点坐标、通过 **「➕ 在图上新增热点」** 在装置图上点击新增部位、更换 `ExamPicture` 工业底图、增删改习题/选项/解析及编辑设备仪表模板；所有修改实时落库 SQLite、追加 `WMPSES_题库变更日志` 审计留痕，并自动同步导出最新 FileMaker CSV 种子文件。
4. **单表统一人员认证、SHA-256 密码安全与 `[未登录]` 操作拦截**：
   - 在 `WMPSES_用户人员` 单表中以 `RoleType` 区分 **考生、命题教师、审题专家、考评员、监考员、系统管理员**，并新增 `Password` 列采用 **SHA-256 哈希加密存储**（预设初始密码统一为 `123456`）。
   - 支持 **系统统一登录验证**、**用户自助修改个人密码**（`🔑 修改密码`）及 **按角色动态控制顶部按钮、工作模式与后台标签页可见性**。
   - 退出当前登录后系统切换为 `[未登录]` 安全状态：仅保留右上角 **「🔐 登录系统」** 按钮，隐藏其余功能按钮并锁定主舞台交互（禁用点击、拖拽与弹窗关闭绕过），必须重新验证登录后才可继续操作。
5. **SQLite 11 表关系型数据库 + 台账方案库 + 表驱动否定项引擎**：
   - 与 FileMaker 11 表结构 **1:1 严格对齐**，支持直接在界面 **「⚙️ 数据库 / 题库 -> 🗄️ SQLite 数据库表预览」** 查看全部 11 张表实时记录。
   - **「📋 台账与验收方案」** 收录 4 份现场工况电子台账、6 方面 24 项验收确认单规范（支持一键跳转至图上对应设备）、14 部附录 C 引用国标及否定项规则查看。
   - **「⚖️ 否定项规则表配置」** 支持直接启停 N1/N2-A/N2-B/N3、调整阈值和惩罚动作并落库，交卷判分实时按规则表执行。
   - 主界面已屏蔽临时项目管理甘特图入口，聚焦仿真考核、题库命制与考务管理核心流程。

## 二、快速启动

### 方式 1：启动 SQLite 后台服务（推荐，支持端口自检与局域网多机考试）
- **macOS Finder 一键启动**：直接双击项目根目录的 `启动SQLite后台服务.command`，脚本会自动完成：
  1. **环境与数据库自检**：校验 Python 3、`server.py` 与 `db/schema.sql`；
  2. **端口占用自检与冲突释放**：检测 `8765` 端口若被旧实例占用则自动停止释放；若仍被系统受保护进程占用，自动顺延扫描 `8766~8785` 空闲端口；
  3. **局域网（`0.0.0.0`）IP 自动探测**：默认监听所有网卡接口，在终端与系统界面 **「⚙️ 数据库 / 题库 -> 🔗 数据源与 FileMaker 配置」** 实时显示 **教师本机地址** 与 **同网段考生机免配置访问地址**；同网段其他考生机在浏览器打开 `http://<教师机局域网IP>:8765` 后，前端会自动同源直连教师机 SQLite 数据库。
- **命令行启动**：
  ```bash
  # 默认监听 0.0.0.0:8765，开启端口自检清理旧进程与空闲端口顺延
  python3 server.py

  # 如需仅限本机访问或关闭自动清理/顺延
  python3 server.py --host 127.0.0.1 --port 8765 --no-kill-existing --no-auto-port
  ```
  启动后本机可在浏览器访问 **http://127.0.0.1:8765**（或直接双击 `index.html` 亦可自动连接本地 SQLite 服务）。

### 方式 2：纯离线静态演示
- 无需启动 Python 服务，直接双击打开 `index.html` 即可运行（自动使用内置默认题库、本地用户档案与 `localStorage` 本地缓存，同样支持 SHA-256 本地登录校验与密码修改）。

## 四、工况数值模拟、新增部位与专业仪表模板操作指南

### 1. 热点弹窗中的工况图与数值存储在哪里？如何模拟调整？
- **数据存储位置**：各设备热点的顶部 SVG 样式类型与数值存放在 SQLite **`WMPSES_设备热点`** 表的 `WidgetType` 与 `WidgetParamsJSON` 字段中（离线/导出时对应 `question-bank.js` 中各热点的 `widgetType` 与 `widgetParams`），由 [visual-widgets.js](js/visual-widgets.js) 实时解析绘制。
- **实时模拟调节方式**：
  1. 在 **练习演示** 或 **教师编辑/标点** 模式下点击任意热点，顶部弹窗内会自动渲染 **「🎛️ 现场工况仿真调节器」**；
  2. 拖动压力、液位、温差、超期天数等滑块，或切换阀门开启/关闭、SIS 联锁投用/旁路等下拉选项，上方 SVG 仪表图形会即时联动变化；
  3. 点击 **「↺ 恢复基准值」** 可一键还原；在具备编辑权限时，点击 **「💾 将当前模拟数值保存为题库默认值」** 会将该数值永久写入 SQLite 并将修改记录追加至 `WMPSES_题库变更日志`。

### 2. 如何在装置全景图上新增一个设备部位？
1. 使用 **命题教师**（如 `TC-GY-01`）或 **审题专家 / 系统管理员** 登录系统，切换到顶部 **「🛠️ 教师编辑/标点」** 模式。
2. 点击黄色工具条中的 **「➕ 在图上新增热点」** 按钮（按钮提示将变为「🎯 请在下方图片点击选点（点击取消）」）。
3. 在全景图的目标设备位置单击鼠标，系统即按点击处相对坐标（`X`、`Y` 百分比）生成新设备部位热点并自动写入 SQLite，随后立即弹出 **「编辑热点部位与关联习题」** 编辑器，可继续修改：
   - 设备位号、部位名称、所属验收方面、精确 X/Y 坐标；
   - **「顶部工况可视化卡片」** 选择源及下方对应的仪表工况参数默认值；
   - 通过 **「➕ 新增习题」** 配置该部位的单选/多选/判断试题、分值、缺陷代码/级别、标准依据与解析。

### 3. 如何新增自定义「专业仪表模板」（扩展可视化卡片选择源）？
1. 打开 **「专业仪表模板构建器」**：
   - 在 **热点编辑器** 顶部「顶部工况可视化卡片」右侧点击 **「➕ 新增/管理模板」**；
   - 或在 **「⚙️ 数据库 / 题库 -> 📦 题库管理与考生信息」** 中点击 **「🎛️ 管理专业仪表模板」**。
2. 点击 **「➕ 清空新建模板」**，输入唯一的英文/数字模板编码（如 `pump_seal_monitor`）与下拉显示名称。
3. 分别选择 **左侧面板** 与 **右侧面板** 的 SVG 部件（支持以下 **8 类可自由组合组件**）：
   - `gauge_dial`：圆形指针压力/真空表
   - `pipe_valve_flow`：工艺管线 + 阀门 + 数字流量计
   - `sight_glass`：立式液位计 / 轴承油标视镜
   - `dcs_interlock`：DCS / SIS 联锁与参数趋势看板
   - `flange_bolts`：圆形法兰螺栓紧固检查盘
   - `cert_nameplate`：强检合格证与设备铭牌色标卡
   - `gas_cems_alarm`：气体报警仪 / CEMS 诊断面板
   - `custom_image_card`：自定义上传现场特写图 + 读数角标（选中后可上传局部设备照片）
4. 在参数配置表中调整各可调参数的标签、最小值/最大值/步长、单位和默认值，实时检查底部 **「👁️ 实时 SVG 渲染预览」**。
5. 点击 **「💾 保存模板到数据库」** 写入 `WMPSES_工况卡片模板`（同步更新 `9_WMPSES_工况卡片模板.csv`），新模板会立即出现在「顶部工况可视化卡片」选择列表中（内置 `TPL-01`~`TPL-09` 受保护不可删除，自定义模板支持编辑与删除）。

## 六、本地后台 HTTP REST API 清单（`server.py`）

默认监听 `http://127.0.0.1:8765`，静态资源托管与 API 共端口零跨域开销：

| 方法 | 路径 | 用途说明 |
| :--- | :--- | :--- |
| `GET` | `/api/health` | 健康检查，返回 SQLite 服务状态、监听主机与端口（含自动清理 PID）、本机与局域网访问 URL 列表及 11 表统计 |
| `GET` | `/api/bank` | 获取完整试卷场景、热点（含 `WidgetParamsJSON`）、习题、否定项规则、台账、模板与变更日志 |
| `GET` | `/api/tables` | 返回 SQLite 全部 11 张表的实时结构与行数据快照（供表预览面板使用） |
| `GET` | `/api/users` | 获取人员名册与最近题库变更审计日志 |
| `GET` | `/api/templates` | 获取 `WMPSES_工况卡片模板` 全量模板列表（含内置 `TPL-01`~`TPL-09` 及自定义模板） |
| `POST` | `/api/bank` | 保存前端编辑后的题库、热点坐标、仪表参数与否定项规则，写入变更日志并同步 CSV |
| `POST` | `/api/bank/reset` | 恢复出厂示范题库（保留既有考生考试成绩记录与作答明细）并重建 CSV 种子文件 |
| `POST` | `/api/results` | 写入正式考试交卷成绩主记录（`WMPSES_考试记录`）与逐题作答明细（`WMPSES_作答明细`） |
| `POST` | `/api/users` | 新增或更新 `WMPSES_用户人员` 记录，并同步导出 `7_WMPSES_用户人员.csv` |
| `POST` | `/api/users/delete` | 删除指定人员记录（同步更新 CSV） |
| `POST` | `/api/auth/login` | 按账号（考号/工号/姓名）与密码进行服务端 SHA-256 鉴权验证 |
| `POST` | `/api/auth/password` | 验证原密码后更新当前用户 SHA-256 密码，并同步写入 SQLite 与 CSV |
| `POST` | `/api/templates` | 新增或更新自定义专业仪表模板到 `WMPSES_工况卡片模板`（同步导出 CSV） |
| `POST` | `/api/templates/delete` | 删除指定自定义模板（内置模板受保护不可删除） |

## 七、FileMaker 集成指南

- 内置 `FMDataAdapter`（[js/fm-adapter.js](js/fm-adapter.js)）与全局桥接对象 `window.FMExam`，支持本地 SQLite、`FileMaker.PerformScript` WebViewer 双向脚本、FileMaker Data API (REST) 及自定义 REST 网关。
- `filemaker_script/` 目录已同步提供 **9 份 UTF-8 BOM CSV 种子文件**（`1_`~`9_`）与 **4 份标准 `<fmxmlsnippet type="FMObjectList">` 脚本 XML**，可直接导入 FileMaker Pro 建库运行；详见 [filemaker_script/README.md](filemaker_script/README.md) 与 [FileMaker题库数据库表结构设计手册.md](filemaker_script/FileMaker题库数据库表结构设计手册.md)。
